I build backend and cloud systems, and I’m now moving my focus to AI engineering, specifically agentic systems. What interests me is the software around the model: which decisions belong to the model and which to the harness, and how to measure systems like these.

Precedent Project Historian

Yazılım geliştirmede kararların koddan önce açıkça yazılması, saklanması ve sonraki insan ya da agent çalışmalarında kullanılabilmesi üzerine bir yaklaşım: Project Historian. Precedent bu yaklaşımın implementasyonu.

Project Historian is an approach to software development where decisions are written down before the code, kept, and reused by later human or agent work. Precedent is its implementation.

Coding agent harness deneyiCoding agent harness experiment

Hazır bir agent framework’ü kullanmadan küçük bir coding agent’ın temel parçalarını kendim yazıyorum. Amaç; model, harness, araçlar, state, trace, memory ve değerlendirme arasındaki sınırları uygulamada görmek. Yaklaşım basit: önce varsayım yapmak yerine davranışı ölçmek.

SWE-agent ekibinin mini-swe-agent çalışmasından ilham alıyor: küçük ve okunabilir bir agent’ın ne kadar ileri gidebildiğini göstermesi bu deneyin çıkış noktası oldu.

I’m writing the core pieces of a small coding agent myself, without an agent framework, to see in practice where the boundaries lie between model, harness, tools, state, traces, memory and evaluation. The rule is simple: measure behaviour before assuming it.

Inspired by the SWE-agent team’s mini-swe-agent, which showed how far a small, readable agent can go.

Yanlış çıkan yedi varsayımSeven assumptions that turned out wrong
  • “Dokümantasyonu okuyup provider’ı yazarım.”
  • “Bir değişikliğin etkisini tek koşuyla görürüm.”
  • “Yazdığım bir karar, uygulanmış bir karardır.”
  • “Kaydettiğim bir ders, öğrenilmiş bir derstir.”
  • “İyi bir özet, kaynağın yerini tutar.”
  • “Agent’ın ilk sorunu kötü düzenleme olacak.”
  • “Ölçüm aletim güvenilir.”
  • “I can write the provider from the docs.”
  • “One run shows the effect of a change.”
  • “A decision I wrote down is a decision implemented.”
  • “A lesson I recorded is a lesson learned.”
  • “A good summary can stand in for the source.”
  • “The agent’s first problem will be bad edits.”
  • “My measuring instrument is reliable.”
